# 🌸 Gerador de Frases Motivacionais

Um **Gerador de Frases Motivacionais interativo**, desenvolvido com **HTML, CSS e JavaScript puro**, focado em **bem-estar**, **positividade** e **experiência do usuário**.

O projeto exibe **frases inspiradoras aleatórias**, permite **salvar favoritas**, **compartilhar no WhatsApp** e conta com uma **interface moderna, animada e responsiva** — tudo rodando diretamente no navegador, sem dependências externas.

## 🧠 Como Funciona

1️⃣ Ao abrir a página, o usuário visualiza uma mensagem inicial  
2️⃣ Ao clicar em **“Nova Frase”**, uma frase motivacional aleatória é exibida  

💖 O botão **“Salvar Favorita”**:
- Armazena a frase no navegador  
- Exibe a frase na lista de favoritas  

📋 As frases salvas podem ser:
- Removidas individualmente  
- Apagadas todas de uma vez  

📤 O botão **“Compartilhar no WhatsApp”**:
- Abre o aplicativo com a frase pronta para envio  

🌟 Um **fundo animado com partículas** roda continuamente, enriquecendo a experiência visual  

---

## 💾 Armazenamento Local

As frases favoritas são armazenadas utilizando **`localStorage`**, garantindo que:

📌 Os dados persistam após fechar ou atualizar a página  
📌 Nenhum backend ou dependência externa seja necessário
